# Estudio Maderax · sitio web

Sitio estático de Estudio Maderax (Pachuca, Hgo.).

- `index.html`: página principal (Origen, Proceso con anteproyecto 3D, Detalle, Proyectos, contacto).
- `guia-fotos.html`: lista de fotos por proyecto para el equipo. Cada foto reemplaza un render en `img/`.
- `img/`: imágenes. Las de proyectos son renders 3D provisionales y se cambian por fotos reales con el mismo nombre de archivo.
- `muro3d.js`: modelo 3D del anteproyecto de ejemplo; se carga solo cuando el visitante lo abre.

Publicación: GitHub Pages desde `main`, carpeta raíz. Por ahora lleva `noindex` para que no aparezca en buscadores.
